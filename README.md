# AI Engineer & Agentic AI Engineer — 18-Month Course

A complete, self-paced curriculum to go from Python fundamentals to building **production-grade AI and agentic systems** — framework-independent, cloud-neutral, interview-ready.

Built as full self-teaching Markdown: concepts from first principles, worked examples, graded exercises, and portfolio projects. Importable into Notion or Obsidian.

## What this covers

| Phase | Months | Focus |
|-------|--------|-------|
| **1** | 1–3 | Python & backend foundations (8 detailed weeks) |
| **2** | 4–5 | Computer science & software design |
| **3** | 6–7 | ML & LLM foundations |
| **4** | 8–9 | RAG engineering |
| **5** | 10–12 | Agentic AI engineering (primary specialization) |
| **6** | 13–15 | Production AI & distributed systems |
| **7** | 16–18 | System design & interview prep |
| **Electives** | ongoing | DSPy, Guardrails, Claude ecosystem, voice/realtime, computer-use, reasoning models, long-term memory |

~1,000–1,170 study hours. Python-first by design.

## How to use it

1. Open `ROADMAP.md` for the full plan.
2. Start at `phase-1-python-backend/week-01/day-1.md`.
3. Do each day's lesson + exercises; check answers in `solutions/`.
4. End each week with `assessment.md` — pass gate is **75%**.
5. Track yourself in `PROGRESS.md`.

## Teaching model

- **Full self-contained lessons** — learn from the material, not just links. External resources (CS50P, official docs) are supplementary.
- **Separated solutions** — attempt before you peek.
- **Graded assessments** — conceptual Q&A + coding challenge + rubric (independent impl 40% / concepts 25% / debugging 20% / quality 15%).
- **Projects per week** — everything builds toward a portfolio.

## Regenerating / extending

The course is generated by the prompt in `MASTER_PROMPT.md`. It's **resumable** — point a capable coding agent at it, and it reads `PROGRESS.md`, finds the next ungenerated unit, and continues in chunked passes.
