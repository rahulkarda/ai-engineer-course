## Conceptual answers

**1. Full jitter vs decorrelated jitter**

Full jitter: `wait = random(0, min(cap, base * 2^attempt))` — uniform sample across the full exponential window. Spreads clients evenly over the window. Prefer when you want simple math and don't care about minimum wait.

Decorrelated jitter: `wait = random(base, min(cap, prev_wait * 3))` — each wait is anchored to the previous, spreading the distribution more evenly over time. Preferred in high-cardinality systems (many clients) where synchronized retries are a bigger concern.

For LLM agents: full jitter is fine for single-process agents. Decorrelated jitter is better when hundreds of agent instances share the same upstream API.

**2. Idempotency key for payment tool call**

An idempotency key must be generated by the caller before the first attempt and included in every retry. The LLM client (or the tool wrapper) stores the `(key → result)` mapping. On retry, the server (or wrapper) returns the cached result without re-executing. The key should be stored on the `AgentState` so it survives node re-invocation in LangGraph.

**3. HALF-OPEN with 5 simultaneous requests**

Only 1 probe should be allowed through (the first request). The other 4 should receive `CircuitOpenError` immediately. Allowing all 5 risks re-opening the circuit if the downstream is still flaky — 5 simultaneous probes hitting a partially-recovered service may trigger failures that a single probe would have passed.

**4. Queue behavior under rate limit**

The LLM caller processes at 1 req/s. The queue fills at the production rate minus 1 req/s. Once 50 slots fill (after `50 / (production_rate - 1)` seconds), the producer blocks on `await queue.put()`. The producer's rate effectively drops to 1 req/s — backpressure is working. If the production rate is exactly 1 req/s, the queue stays full but never overflows. If production rate < 1 req/s, the queue drains.

**5. Choreography vs orchestration**

Choreography better: microservices with independent deployment lifecycles and no single owner. E.g., `order-service` emits `order.created`, `inventory-service` reacts, `payment-service` reacts. No central coordinator means no single point of failure.

Orchestration better: complex multi-step workflows where visibility, rollback, and SLA enforcement matter. E.g., a loan approval saga across 6 steps where compliance requires a full audit trail and deterministic compensation order.

**6. Bursting with TPM-limited APIs**

Harmful for strict TPM limits. The token bucket allows sending `capacity` tokens instantly — this burst can exceed the API's per-minute budget and trigger 429s immediately. For TPM-limited APIs, set `capacity = rate * 1s` (no effective burst) or use a leaky bucket that enforces constant throughput. The token bucket is appropriate for RPM (request-per-minute) limits where burst is acceptable within the minute window.

**7. Steady-state in chaos engineering**

Steady-state is a measurable, quantitative definition of "the system is healthy" — e.g., "p99 latency < 500 ms, error rate < 1%, 99% of requests served." You define it first because chaos experiments are falsifiable only if you know what "normal" looks like. Without a baseline, you cannot tell whether a failure mode you introduced changed anything.

**8. Fallback without circuit breaker**

If backup LLM becomes slow/overloaded, every call to the fallback will wait for `call_timeout_s` before failing. With 5 retries and a 30-second timeout, a single failing request can take 150 seconds. Fix: wrap each fallback transport in its own circuit breaker. When the fallback's CB opens, the fallback chain advances to the next option (or static response) without waiting.

## Coding challenge — reference solution

```python
"""
assessment_solution.py — ReliableAgentNode for LangGraph.
All LLM calls mocked. No real API calls.
"""

import asyncio
import logging
from typing import Any
from unittest.mock import AsyncMock

from pydantic import BaseModel, Field

from reliability_toolkit.client import LLMRequest, ResilientLLMClient

logger = logging.getLogger(__name__)


class AgentState(BaseModel):
    prompt: str
    idempotency_key: str | None = None
    response: str = ""
    degraded: bool = False
    attempt_count: int = 0
    error: str = ""


async def reliable_agent_node(
    state: AgentState,
    client: ResilientLLMClient,
) -> AgentState:
    """
    LangGraph-compatible node: calls the LLM via ResilientLLMClient.
    Never raises — all errors captured in state.error.
    """
    request = LLMRequest(
        prompt=state.prompt,
        idempotency_key=state.idempotency_key,
    )
    try:
        resp = await client.complete(request)
        return state.model_copy(update={
            "response": resp.content,
            "degraded": resp.degraded,
            "attempt_count": resp.attempt_count,
            "error": "",
        })
    except Exception as exc:
        logger.exception("reliable_agent_node: unhandled error")
        return state.model_copy(update={
            "response": "",
            "error": str(exc),
            "degraded": True,
        })
```

### Tests

```python
import pytest


def make_failing_transport(n_failures: int) -> AsyncMock:
    transport = AsyncMock()
    call_count = 0

    async def complete(prompt: str, model: str) -> str:
        nonlocal call_count
        call_count += 1
        if call_count <= n_failures:
            from reliability_toolkit.retry import TransientError
            raise TransientError("transient")
        return f"Success on attempt {call_count}"

    transport.complete.side_effect = complete
    transport._call_count = lambda: call_count
    return transport


@pytest.mark.asyncio
async def test_happy_path() -> None:
    transport = make_failing_transport(0)
    client = ResilientLLMClient(primary=transport)
    state = AgentState(prompt="hello")
    result = await reliable_agent_node(state, client)
    assert not result.degraded
    assert result.response != ""
    assert result.attempt_count >= 1
    assert result.error == ""


@pytest.mark.asyncio
async def test_retry_three_attempts() -> None:
    transport = make_failing_transport(2)
    client = ResilientLLMClient(primary=transport)
    state = AgentState(prompt="retry test")
    result = await reliable_agent_node(state, client)
    assert result.attempt_count == 3
    assert "Success" in result.response


@pytest.mark.asyncio
async def test_total_failure() -> None:
    transport = make_failing_transport(999)  # always fails
    client = ResilientLLMClient(primary=transport, fallbacks=[])
    state = AgentState(prompt="doom")
    result = await reliable_agent_node(state, client)
    assert result.response == "" or "unavailable" in result.response.lower()
    assert result.degraded
```
