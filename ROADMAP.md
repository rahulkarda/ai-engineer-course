# AI Engineer & Agentic AI Engineer — 18-Month Roadmap

> Master index. Python-first, framework-independent, production-focused.
> Target: independently build production-grade AI systems using any reasonable framework or cloud.

## Phase structure

| Phase | Months | Domain | Weeks | Status |
|-------|--------|--------|-------|--------|
| P1 | 1–3 | Python & backend foundations | 8 (detailed) + ramp | Pending |

Total budget: ~1,000–1,170 study hours.

## Eight mandatory domains (the common core)

1. Python & software engineering
2. Backend engineering
3. ML & LLM fundamentals
4. RAG & knowledge systems
5. Agentic AI engineering
6. Production AI engineering
7. Security & responsible AI
8. System design & engineering leadership

## Mandatory projects portfolio

1. Python backend platform — Python, FastAPI, SQL, testing, async, architecture
2. Advanced RAG system — LLMs, embeddings, retrieval, vector DB, evaluation
3. Multi-agent operations platform — agent architecture, MCP, A2A, LangGraph, security
4. Production AI platform — distributed execution, observability, Docker, k8s, CI/CD, cost

## Electives (full lessons, lower priority)

- Cloud specialization: AWS Bedrock/AgentCore/Strands, Azure OpenAI/AI Foundry, Google Vertex/ADK
- AI infrastructure: vLLM, TGI, MLflow, Ray, GPU optimization, quantization
- Agent ecosystems: CrewAI, AutoGen, LlamaIndex, Agno, Copilot Studio
- Extra domains: Graph RAG, multimodal, voice AI, fine-tuning/LoRA
