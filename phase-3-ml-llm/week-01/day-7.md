## Project Checklist

Before submitting, verify all of the following:

- [ ] `ops.py` — vector and matrix ops with type hints, no raw loops for matmul
- [ ] `activations.py` — sigmoid, ReLU, tanh + their gradients
- [ ] `losses.py` — MSE, binary CE, multi-class CE
- [ ] `optimizer.py` — gradient descent, mini-batch GD, optional momentum
- [ ] `tests/` — at least 10 passing pytest tests covering the above
- [ ] `README` in the project folder — how to run, what each module does
- [ ] No hardcoded magic numbers — use named constants or function arguments
- [ ] No `print()` calls — use `logging`
